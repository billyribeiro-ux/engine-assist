# S-0 · PTY, xterm 6, the real TUI and the strict CSP (M0-12)

Class HARD · manual (Billy on his Mac) · ADRs 006, 014, 002, 020 · threats T-012, T-013, T-091 · ACs AC-M0-13 (S-0), AC-M0-14, AC-M0-08, AC-F009-06, AC-F009-08, AC-F009-15, NFR-23.

**Question.** Does the real Claude Code TUI work in xterm 6 fed by portable-pty inside a Tauri WKWebView (Shift+Tab, a 5 KB paste, resize while streaming, ⌘K routing, ⌘C/⌘V, VoiceOver, memory with 3 tabs after 30 minutes), and does the strict production CSP (`style-src 'self'` plus Tauri's hashes and nonces) hold with Bits UI, Svelte transitions, xterm and the SvelteKit bootstrap script?

**Run this one first:** a fundamental TUI failure stops M1 and reopens the shell choice (SwiftUI + SwiftTerm), so S-0 goes before the other six.

## Harness requirements (the one thing this kit does not contain)

S-0 needs real code that is thrown away afterwards (`spikes/s0/`: a throwaway Tauri route plus the `portable-pty` wrapper; never imported by the app; build-prompts 5.3). It must follow ADR-006 and ADR-014 closely enough that a pass means something:

- `PtySession` over `portable-pty` 0.9.0: absolute `claude` path, `env_clear()` plus the SR-05 allowlist, argv from the Master Spec §6 shape (`--session-id`, `--model`, `--effort`, `--permission-mode`, `--name`, `--settings <run settings file>`), output as raw bytes over a `Channel<tauri::ipc::Response>`, `pty_write`, `pty_resize`, `pty_paste`.
- Three terminal tabs, each a real `claude` session in a throwaway folder (plan mode is fine; the folder must be trusted once).
- xterm 6.0.0 with `@xterm/addon-fit`, `@xterm/addon-webgl` (DOM fallback), `@xterm/addon-unicode11`, `@xterm/addon-search`; `scrollback: 10000`; `windowOptions` all false; no clipboard addon; `attachCustomKeyEventHandler` routing per ADR-006 (⌘-chords and ⌃` to the app except ⌘C, ⌘V, ⌘A, ⌘F; ⌘⇧E back to the workspace).
- SR-28 paste path: ⌘V reads the clipboard in Rust, `core::sanitize::for_paste` removes every ESC and the C0/C1/DEL controls (TAB, LF, CR kept), the webview calls `term.paste(sanitized)`, a visible notice reports what was removed, xterm's own paste handling is off.
- CSP: `tauri.conf.json` with the production `csp` from ADR-014 (not `devCsp`), `kit.csp` unset, `freezePrototype: true`. A page with a Bits UI dialog, popover and select, a Svelte `fade`/`slide`/`fly` transition, a keyboard shortcut ⌘K that opens a palette in the app, and SvelteKit's default `version.json` polling configuration with `pollInterval: 0` (ADR-002).
- Web Inspector: release builds have no devtools (SR-21). Use a **debug build that still carries the production CSP** (`pnpm tauri build --debug`; confirm which CSP is active by reading the `Content-Security-Policy` header or meta in the Inspector, since `tauri dev` uses `devCsp` instead) and open Inspector with right-click, Inspect Element.

If any of these is missing, say so in the Results and mark the dependent rows "not tested" rather than PASS.

## Fixtures and helpers

```bash
pnpm spikes s0 fixtures            # writes ~5 KB paste, the SR-28 fixture and a control-character text under $TMPDIR/foreman-spikes/s0/fixtures
pnpm spikes s0 clip 5kb            # puts a fixture on the clipboard (5kb | sr28 | ctrl)
pnpm spikes s0 pwn arm             # removes /tmp/pwn
pnpm spikes s0 pwn check           # PASS if /tmp/pwn still does not exist
pnpm spikes s0 mem --minutes 30    # ps sampler for the memory row (see below)
```

The SR-28 fixture is exactly the 23 bytes `\x1b[201~\x03!touch /tmp/pwn\r`.

## Checklist

Do the rows in order. Record PASS, FAIL or NOT TESTED in the table at the end, with evidence (a note, a screenshot path, a number).

### A. Terminal behavior with the real TUI

**A1 Shift+Tab.** In a tab at the Claude prompt, press Shift+Tab repeatedly. Pass: the TUI's mode indicator cycles through its permission modes (watch the footer), the key reaches the PTY every time, and Foreman's page does not move focus.

**A2 5 KB paste.** `pnpm spikes s0 clip 5kb`, focus the tab, ⌘V. Pass: the whole text arrives in order (the input box shows a paste summary or the text; submit nothing), the last line `END-OF-5KB-PASTE` is present when expanded or when you press Enter to a throwaway prompt and read Claude's echo of the last line, no freeze, no dropped lines, and the paste arrives as one bracketed block.

**A3 SR-28 fixture (nothing runs).** `pnpm spikes s0 pwn arm`; `pnpm spikes s0 clip sr28`; ⌘V in a live Claude tab (it is a **real session** on purpose). Pass: Foreman shows the "removed N control characters" notice, the input box contains no ESC-driven edits and no submitted command, and then `pnpm spikes s0 pwn check` prints PASS (`/tmp/pwn` does not exist). Also paste `ctrl` (`pnpm spikes s0 clip ctrl`): the letters a to h must arrive with the controls stripped (TAB and line breaks kept) and a notice. A FAIL here is a security failure of the sanitizing path (SR-28), not a layout issue: stop and report it before anything else.

**A4 Resize while streaming.** Ask Claude: `Print the numbers 1 to 400, one per line, then a 15-line paragraph about nothing in particular.` While it streams, drag the window edge, toggle full screen and drag the sidebar if the harness has one, ten times in total. When it finishes, type `!stty size` (bash mode in the TUI) and compare rows and columns with what the terminal shows. Pass: no garbled or duplicated lines after the reflow, no crash, `stty size` matches the visible grid, and the text keeps streaming.

**A5 ⌘K routing.** With the terminal focused press ⌘K, then ⌘, and ⌃` if the harness binds them. Pass: each reaches the app (palette opens) and none of them appears in the TUI input box or reaches the PTY (no stray `^K`). Then press ordinary keys, Tab, Escape and ⌃C: they must reach the PTY (Escape and ⌃C visibly act in the TUI).

**A6 ⌘C / ⌘V / ⌘A / ⌘F in the terminal.** Select text with the mouse, ⌘C, paste it into another app: it copies. ⌘C with **no** selection: record what happens (it must not send an interrupt unless the spec says so; AC-F009-08 says ⌘C copies the selection). ⌘V pastes into the PTY (A2). ⌘A selects the terminal buffer; ⌘F opens the search addon. Pass when all four behave as AC-F009-08 states.

**A7 No keyboard trap.** From inside the terminal press ⌘⇧E: focus must return to the workspace. Then Tab through the app and back into the terminal. Pass: you can always leave the terminal with the keyboard.

**A8 VoiceOver.** Turn VoiceOver on (⌘F5). With the harness at its default (`screenReaderMode` off), move VoiceOver into the terminal and into a tab while Claude prints a short answer; note what is announced. Turn `screenReaderMode` on (and, in a second launch, `claude --ax-screen-reader` through the harness) and repeat. Pass: with one of these settings VoiceOver reads new output and the prompt line, and tab switching is announced. If only the second setting works, the fail branch is `--ax-screen-reader` (Settings → Screen reader mode, MASTER-SPEC §6). Record exactly what VoiceOver said.

**A9 Memory with 3 tabs after 30 minutes.** Open exactly three tabs, each running a real `claude`; in each, ask for the 400-line output of A4 so every tab has scrollback. Close Safari and any other WebKit apps (their WebContent processes would be counted). Start the sampler and leave everything idle but alive:

```bash
pnpm spikes s0 mem --minutes 30 --interval 60 --match foreman
```

It sums RSS from `ps` for the app, its `claude` children and the WebKit helper processes, writes a CSV and prints PASS when the end total is at most 300 MB (NFR-23) and 3 `claude` children existed. RSS double-counts shared pages: also read Activity Monitor (Memory column; View, All Processes) for the app, its WebContent and GPU helpers and the three `claude` processes, and record both. Pass: ≤ 300 MB by both measures. Fail: record measured MB and apply "measured + 20 %".

### B. Strict CSP in the WKWebView

Use the debug build with the production CSP (see Harness requirements). Open Inspector, Console and Network, reload, and keep the console open for the whole section. Count violations by kind (`Refused to execute inline script`, `Refused to apply inline style`, `Refused to connect`).

**B1 Boot.** Cold start. Pass: the page renders, SvelteKit's single inline bootstrap script runs (Tauri's hash in `script-src`), zero violations, and the CSP in force is the production one (no `'unsafe-inline'` or `'unsafe-eval'` in `script-src`; no `localhost:5173`).

**B2 xterm.** Open a terminal tab and stream output (A4 text). Pass: zero CSP violations, text renders in the webgl renderer and again after forcing the DOM renderer (disable the webgl addon in the harness), and selection highlighting works. If xterm's injected `<style>` is blocked, note the exact message: that is the `style-src` finding.

**B3 Bits UI.** Open and close a dialog, a popover and a select, with the keyboard and the mouse. Pass: zero violations, positioning (floating-ui sets inline styles) and focus trapping work.

**B4 Svelte transitions.** Trigger `fade`, `slide` and `fly` on a list item and on a dialog. Pass: zero violations and the animation visibly runs.

**B5 Inline script stays blocked.** In the console run:

```js
document.body.append(Object.assign(document.createElement('script'), { textContent: 'window.__pwned = 1' }));
window.__pwned;
```

Pass: a `Refused to execute inline script` violation appears and `window.__pwned` is `undefined`.

**B6 `version.json` polling (ADR-002, UNVERIFIED).** With `kit.version.pollInterval: 0`, watch Network while you switch to another app and back, and wait two minutes. Pass (no change needed): no request to `…/_app/version.json`. If a request appears, or a `Refused to connect` appears for it: `connect-src` gains `'self'` and ADR-014 records it (AC-M0-08 snapshot updates).

**B7 Dev note.** `docs/dev-notes.md` expects `tauri dev` styling to be blocked by `devCsp` (Vite injects `<style>`). If you see that, record it as a finding; it is not a reason to loosen the production CSP.

## Decision

**Pass branch (every A and B row PASS):** xterm 6 + portable-pty ship as specified; M1 continues.
Documents changed: `docs/adr/ADR-006-pty-and-terminal.md` (Status: S-0 verified; add the measured MB and VoiceOver result), `docs/adr/ADR-014-csp-and-tauri-capabilities.md` (S-0 CSP check recorded; `connect-src` only if B6 requires it), `docs/scope.md` (nothing else).

**Fail branch (any row FAIL; apply every matching item):**

- Scrollback cap and archive: `docs/scope.md` AC-F009-06 (cap value from the measurement), ADR-006.
- A key-routing layer: AC-F009-08, ADR-006 (the `attachCustomKeyEventHandler` table).
- `--ax-screen-reader`: ADR-006, Settings contract (`docs/contracts`), MASTER-SPEC §6 flag list.
- Memory NFR raised to measured + 20 %: NFR-23 in `docs/scope.md`, MASTER-SPEC §10 (`≤ 300 MB`).
- CSP `style-src 'unsafe-inline'` only (scripts stay strict): ADR-014 (accepted risk: CSS injection without script execution), AC-M0-08 and the `csp::production_config_snapshot` test target.
- `connect-src` gains `'self'` (B6): ADR-014, AC-M0-08.
- A fundamental TUI failure (A1, A2 or A4 broken in a way a layer cannot fix): **stop M1 and tell Billy**; the shell choice reopens (SwiftUI + SwiftTerm, ADR-001).
